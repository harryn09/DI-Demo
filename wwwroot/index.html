Why it matters

Built for trust,
not for friction

Security by default

Multi-factor authentication and evidence-of-identity verification protect every account.

Set up in minutes

School IT administrators can register for the Learner Identity Broker in 10–15 minutes.

Self-service management

Delegated Authorisers manage organisation accounts; users manage their own — no waiting.

Moves with the learner

Records and access transfer seamlessly when a learner changes schools — no starting over.

One record, one NSN

A single lifelong National Student Number keeps learner information accurate everywhere.

Privacy protected

Information is shared safely between authorised services only, under strict privacy rules.
